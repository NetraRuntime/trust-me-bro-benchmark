# Security

Do not put credentials, private prompts or response dumps in public issues.

Use [GitHub private vulnerability reporting](https://github.com/NetraRuntime/trust-me-bro-benchmark/security/advisories/new) if enabled. If it is unavailable, open an issue containing only a request for a private contact channel; do not include vulnerability details until a private channel is established.

Include the affected version, a minimal synthetic reproduction and expected/observed behavior. Remove tokens, identifiers and personal data. If a key was exposed, revoke/rotate it with the provider. This initial release does not promise a security-support SLA.
