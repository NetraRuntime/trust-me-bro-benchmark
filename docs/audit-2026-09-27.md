# Statistical audit and remediation: version 0.3.0

The review examined version 0.2.0 at commit
`2350fab4a4d157cdf2775c5cf6e0aeb2422cf8d0`. Its acceptance criterion was
whether the benchmark can detect statistically different provider response
distributions on the tested prompts. Proving model identity or equivalence
was outside that criterion. This is an implementation review and remediation
record, not independent third-party certification.

The primary categorical MMD statistic, within-question permutation test,
Holm correction and complete-protocol failure rule remain unchanged.
The audit found implementation defects and an unsupported interpretation
in the optional baseline procedure.

## Findings and corrections

| Finding | Version 0.3.0 correction |
|---|---|
| Shared API seeds can couple repeat aliases and undermine sampling independence. | Reject non-null API request seeds for new statistical collections; mark historical seeded inference inconclusive. Local schedule and analysis seeds remain available. |
| Offline reports accepted inconsistent protocol declarations and unbound item metadata. | Validate protocol/configuration agreement, fingerprints and per-request settings in CLI, MCP and resume paths. Bind saved dataset metadata into schema-2 fingerprints; optionally verify original frozen-dataset linkage. |
| Duplicate observations could replace required repeat slots. | Validate planned endpoint/item/repeat identities, uniqueness, repeat ranges, statuses and successful choices before analysis. Check retained response text against its digest and parsed choice. |
| Detailed tables omitted missing observations when surviving responses agreed. | Include every missing-answer question with valid/planned counts and failure statuses, and explain inconclusive pairwise inference. |
| The optional baseline bootstrap lacks calibrated simultaneous coverage. | Make new baseline outputs descriptive-only. Preserve historical calculations with explicit calibration warnings. Statistical significance comes from the separate distribution test. |

The rare-question bootstrap counterexample and observation-validation
regressions are retained in [test_consistency.py](../tests/test_consistency.py)
and [test_validation.py](../tests/test_validation.py). Method definitions
and limitations are documented in the [dataset protocol](dataset-protocol.md),
[baseline method](consistency.md) and [interpretation guide](interpreting-results.md).

## Verification performed

- Full offline suite: **96 passed** on Windows 11 and Python 3.12.11.
- `ruff check .` and `git diff --check`: passed.
- Fresh synthetic dataset demo: **2,400/2,400** successful mock responses;
  three pairs with no detected difference, three detectably different,
  and all five optional baseline comparisons descriptive-only.
- Fresh legacy level-4 collection and offline report: **495/495** successful
  mock responses, with no remaining requests.
- Independent audit arithmetic checked 368 MMD sample combinations and
  1,296 Holm inputs, plus an enumerated small permutation example.

The operating-system/Python CI matrix was not run remotely during this
review. These local results do not claim cross-platform certification or
general statistical power. No paid inference calls were made during
remediation. Detailed local audit records, original provider observations
and derived live reports remain outside Git under the repository's
[privacy policy](privacy.md).

## Remaining boundaries

A completed valid test with adjusted p above alpha means no difference was
detected at the tested sample size. Missing required responses yield an
inconclusive result; implementation fixes cannot supply historical missing
data. A new study must predeclare its settings and failure policy.

Local hashes detect inconsistent edits, but do not prove external
preregistration, API delivery or provider compliance with requested controls.
Original dataset linkage is explicitly unverified unless the frozen dataset
is supplied. Provider independence and hidden serving conditions remain
assumptions that cannot be established from a manifest alone.
